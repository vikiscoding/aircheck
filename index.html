    Mild, clear and dry with low air-quality risk — comfortable for most people.

    Ideal for walking, cycling or outdoor sports.

    A sun line is separate from that sentence. At UV index 10, for very fair skin, the rule says: Very high burn risk in ~10–20 min of direct sun for very fair skin. That line is a sample of the rule, not a live reading.

    How a reading works

    The sentence comes from a fixed table written ahead of time. Nothing on this page asks a model to describe the weather. The UV index and cloud cover come from that same reading. A fixed rule turns the UV index, and a skin type if you set one, into a burn-time range. Minutes equal a published skin-type dose divided by the UV index times 1.5. The range is an estimate for unprotected skin in the sun, not a personal limit.

    1. You give a place, or you allow a one-time location reading.
    2. The page asks Open-Meteo for the current weather, UV index, cloud cover, and air quality.
    3. It turns those readings into bands and looks up a sentence in the table.
    4. You see the sentence, the sun line when the UV index is 3 or higher, the numbers, the time, and the source.

    The sentence describes that reading. It is not a forecast for later in the day. If the table has no row, the numbers stay on the page with a note that no sentence was written for them.

    UV index and burn time

    The sun line sits under the feel sentence when the rounded UV index is 3 or higher. A rounded index of 0, 1, or 2 is low, so the page shows the number and no sun sentence. Above that, moderate is 3–5, high is 6–7, very high is 8–10, and extreme is 11 or above.

    The minutes use the UV index that already includes cloud cover. Clear-sky UV is shown as its own number. Choose a Fitzpatrick type to see the range. With no type selected, the line names the band.

    Privacy

    No account. No history. If you use your location, the coordinates are used once for the request and then discarded. This page does not use cookies or analytics. A skin type is saved on this device only if you choose Remember.
